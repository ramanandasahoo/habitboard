              How this is counted
              • Weeks run Sunday to Saturday, using this phone's dates.
              • A task counts once per week if it was on your list on any day of that week: scheduled that week, or carried over unfinished from an earlier day. It counts as done in the week you ticked it.
              • Tasks ticked on a future date are not counted as done.
              • A habit day counts as done only if your habit history has that date. Days after today, and days before you added the habit, are not counted.
              • Overall is the average of the task rate and the habit rate, so tasks and habits count equally. If only one of them has anything to count, overall shows that one and says so.
              • Deleting a task or habit also removes it from the statistics.

              Reminders

              Notifications from HabitBoard are best effort. Android and Chrome decide when background checks run, so a reminder can be late or missing while HabitBoard is closed. For a dependable alarm, add the daily calendar reminder below.

              How to add the calendar reminder
              1. Choose your reminder time above, then tap “Add daily reminder to calendar (.ics)”. A file named habitboard-daily-reminder.ics is downloaded.
              2. Open it: tap the download notification, or open Files → Downloads and tap the file.
              3. Choose your calendar app (for example Google Calendar) and tap Add or Save. The event repeats every day at your time.
              4. Open the new event once and check it has a notification at the time of the event. Some calendar apps ignore the alarm inside the file and use their own default reminder, so add one if needed.
              5. To change the time later: delete that event, change the time here, and download the file again.

              Notifications always use the same generic text. They never include your task names or notes. Reminder settings stay on this device and are not part of backups.
